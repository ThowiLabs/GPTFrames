04 / 07SEPARACIÓN DE RESPONSABILIDADES

CADA MÓDULO, UNA TAREA

La misma aplicación puede tener archivos con responsabilidades bien definidas.

PY

pagos.py

def cobrar(pedido):
    return banco.cobrar(
        pedido.total)
PY

inventario.py

def reservar(pedido):
    return stock.restar(
        pedido.id)
PY

avisos.py

def notificar(pedido):
    return correo.enviar(
        pedido.email)

El criterio es la responsabilidad, no simplemente crear más archivos.

07 / 07CONCLUSIÓN PRÁCTICA

No modularices por moda. Cuando crezca la complejidad, diseña piezas claras y fáciles de probar.
